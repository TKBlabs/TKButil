# TKButil

macOS用のメニューバー常駐型ユーティリティです（Dockにアイコンは出ません）。クリップボード履歴と定型文を中心に、ウィンドウ切り替え、ウィンドウ位置の固定、複数ディスプレイでのDock移動抑止、マウスごとのスクロール・カーソル調整、サウンド出力先の優先度制御をひとつにまとめています。機能はそれぞれ個別にオン・オフでき、必要なものだけを使えます。

- **ダウンロード**: [Releases](https://github.com/TKBlabs/TKButil/releases)（最新版のDMG）
- **製品ページ**: https://apps.tkbtk.com/TKButil/
- **動作環境**: macOS 26.5以降、Apple Silicon（Intel Macには対応していません）
- **ライセンス**: フリーウェア（個人・商用を問わず無料）

## インストール

1. [Releases](https://github.com/TKBlabs/TKButil/releases)から最新版の `TKButil_<バージョン>.dmg` をダウンロードします。
2. DMGを開き、`TKButil.app` を「アプリケーション」フォルダへドラッグします。
3. 「アプリケーション」フォルダから起動します。メニューバーにTKButilのアイコンが表示されます。

アプリとDMGはどちらもAppleの公証（Notarization）を受けています。初回起動時に「インターネットからダウンロードされたアプリケーションです」と確認が出たら「開く」を押してください。

> [!IMPORTANT]
> DMGの中やダウンロードフォルダから直接起動すると、自動アップデートがうまく動かないことがあります。「アプリケーション」フォルダ以外から起動した場合は、TKButilが移動を勧めます。「移動して起動し直す」を選ぶと、移した先で起動し直します。

### 使う機能に応じて必要な許可

| 機能 | 必要な許可（システム設定 →「プライバシーとセキュリティ」） |
| --- | --- |
| 履歴・定型文の自動貼り付け | アクセシビリティ |
| ウィンドウ固定 | アクセシビリティ |
| ウィンドウ切り替え | アクセシビリティ（サムネイルを表示するには画面収録も） |
| マウス調整 | アクセシビリティ、入力監視 |

設定画面の各タブに、許可の状態の確認や「システム設定」を開くボタンがあります。

## アップデート

自動アップデート（Sparkle）に対応しています。

- 24時間ごとに新しい版を確認します（設定の「更新」タブでオン・オフできます）。
- メニューバーアイコンの右クリックメニュー「アップデートを確認...」、または設定の「更新」タブの「今すぐ確認」で、すぐに確認することもできます。
- 更新ダイアログで「今後は自動でダウンロードしてインストールする」をオンにすると、以後は確認なしで裏でダウンロードし、TKButilの終了時に新しい版へ入れ替えます。

各版の変更点は[Releases](https://github.com/TKBlabs/TKButil/releases)に載っています。

## 使い方

- **メニューバーアイコンを左クリック**: クリップボード履歴と定型文の画面（左クリック画面）を開きます。設定の「一般」タブで、この画面を開くショートカットも登録できます。
- **メニューバーアイコンを右クリック**: 各機能（クリップボード監視／Dock移動抑止／ウィンドウ固定／ウィンドウ切り替え／マウス調整／サウンド優先度）のオン・オフ、「履歴を表示」「設定」（⌘,）「アップデートを確認...」「終了」（⌘Q）のメニューを開きます。

## 主な機能

### クリップボード履歴

- コピーしたテキスト・URL・画像を自動で記録し、左クリック画面に種類ごとの枠で一覧表示します。画像はサムネイルで表示します。
- 履歴を選ぶとクリップボードに戻します。設定で「選択したら自動で貼り付ける」（前面のアプリへ貼り付け）、「選択したら先頭へ移動する」をオンにできます。
- 検索欄で絞り込めます。先頭に `u `（URL）、`g `（画像）、`s `（定型文）と入力すると、その種類だけを検索します。
- 履歴の行から、テキストやURLをフォルダを選んで定型文に保存できます。
- 保存件数の上限は種類ごとに1〜500件。「適用」で反映し、上限を超えて消える履歴があるときは事前に確認します。
- 記録しないURLのドメインを指定できます（`*` と `?` のワイルドカードに対応。`*.example.com` は example.com とそのサブドメインに一致）。該当するURLを含むコピーは記録しません。
- Excelでセル・行・列をコピーしたときにテキストとして記録するかを選べます。

### 定型文

- タイトルと内容の組をフォルダで分類して登録し、左クリック画面からすぐに貼り付けられます。
- フォルダ・定型文ごとに表示・非表示を切り替えられます。
- CSVでのインポート・エクスポートに対応しています。

### ウィンドウ切り替え

- アプリ単位ではなく、ウィンドウを1枚ずつ選んで前面に出します。ウィンドウのサムネイル（画面収録の許可が必要）、ウィンドウ名、アプリ名とアイコンを並べて表示します。
- 既定のショートカットは Option + Tab。設定で好きなキーに変えたり、⌘Tab を直接割り当てたりできます。⌘Tab を割り当てると、機能が有効な間はmacOS標準のアプリ切り替え（⌘Tab／⇧⌘Tab）を置き換えます。OSの設定は変えず、機能をオフにするかTKButilを終了すると標準の⌘Tabに戻ります。
- 最小化されたウィンドウを別の段にまとめて表示することもできます。選ぶと最小化を解除して前面に出します。
- サムネイルのサイズを変えられます。

### ウィンドウ固定

- 接続しているディスプレイの組み合わせ（モニタ構成）ごとに、アプリのウィンドウの位置とサイズを登録します。
- アプリの起動時やモニタ構成が変わったときに、登録した位置へ自動で戻します。スクリーンセイバー・ロックからの復帰時にも適用するかを選べます。
- 起動直後は10秒間、毎秒適用し直す設定があります（再起動直後に位置がずれるのを防ぎます）。
- 登録した位置をその場で適用するショートカットを設定できます。

### Dock移動抑止

- 複数ディスプレイの環境で、メインではないディスプレイのDockが出る端にカーソルが触れたときにDockが別のディスプレイへ移ってしまうのを防ぎます。
- クラムシェルモードの解除などディスプレイ構成が変わる間は、一時的に止めます。

### マウス調整

- 接続中のマウスを一覧で表示し、マウスごとにホイールのスクロール量（1ノッチあたり1〜20行）、スクロールの反転、スクロールの加速、カーソルの速度と加速度を設定できます（内蔵・Apple純正のトラックパッドは対象外です）。
- スクロールの「反転」は、チェックを入れるとWindowsと同じ向きになります。
- 設定はマウスごとに保存し、次に接続したときに自動で反映します。
- SteerMouse や Logi Options など、同じ設定を書き換えるアプリが動いているときは知らせ、終了させるボタンを表示します。

### サウンド優先度

- 検出した音声出力デバイスに優先度（1〜10）を付け、接続中のものの中で優先度がいちばん高いデバイスへ自動で切り替えます。
- たとえばBluetoothのヘッドホンを高く、MacBook本体のスピーカーを低くしておくと、ヘッドホンをつないだときだけヘッドホンから音が出ます。

## 主なショートカット

| 操作 | キー |
| --- | --- |
| 左クリック画面を開く | 設定の「一般」タブで登録（既定はなし） |
| ウィンドウ切り替え | Option + Tab（設定で変更、⌘Tab も可） |
| ウィンドウ切り替え中: 選択の移動 | Tab ／ ⇧Tab、矢印キー |
| ウィンドウ切り替え中: 決定／キャンセル | 修飾キーを離す・Enter ／ Esc |
| 登録したウィンドウ位置を今すぐ適用 | 設定の「ウィンドウ固定」タブで登録（既定はなし） |
| 設定 | ⌘,（右クリックメニュー） |
| 終了 | ⌘Q（右クリックメニュー） |

ショートカットは、キーと修飾キー（⌃⇧⌥⌘）の組み合わせのほか、修飾キーだけの組み合わせや、単独の修飾キーの2回押しも登録できます。修飾キーの2回押しで開いたウィンドウ切り替えは、矢印キーで選んでEnterで決定します。

## 設定

設定は9つのタブに分かれています。

| タブ | 内容 |
| --- | --- |
| 一般 | ログイン時に自動で起動、設定画面と左クリック画面の表示倍率（UIスケール）、左クリック画面を開くショートカット、コピーしたら画面を閉じる |
| クリップボード | 履歴の表示行数（1〜12行）、自動貼り付け、選択したら先頭へ移動、Excelのコピーの記録、記録しないURLのドメイン、種類ごとの保存件数の上限と保存容量 |
| 定型文 | フォルダと定型文の追加・編集・並べ替え・表示切り替え、CSVのインポート・エクスポート |
| Dock | Dock移動抑止のオン・オフ、旧方式で変えたフルスクリーン時の表示設定を戻す |
| ウィンドウ固定 | ウィンドウ固定のオン・オフ、復帰時にも適用、起動直後の再適用、今すぐ適用のショートカット、現在のモニタ構成とその登録の一覧（登録・削除・今すぐ適用） |
| ウィンドウ切り替え | ウィンドウ切り替えのオン・オフ、最小化されたウィンドウの表示、ショートカット、⌘Tabで切り替える、サムネイルのサイズ、許可の確認 |
| マウス | マウス調整のオン・オフ、接続中のマウスごとの設定、保存済みの設定の削除・リセット、許可と競合アプリの確認 |
| サウンド | サウンド優先度のオン・オフ、優先度1〜10への出力デバイスの割り当て、未接続のデバイスの整理、リセット |
| 更新 | 自動で更新を確認するかどうか、最後に確認した日時、「今すぐ確認」、現在のバージョン |

## 困ったときは

- **自動貼り付け・ウィンドウ固定・ウィンドウ切り替えが動かない**: システム設定 →「プライバシーとセキュリティ」→「アクセシビリティ」でTKButilがオンになっているか確認してください。アップデート後にうまく動かないときは、一度オフにしてからオンにし直してください。
- **ウィンドウ切り替えにサムネイルが出ない**: 「画面収録」の許可が必要です。切り替え画面の案内か、設定の「ウィンドウ切り替え」タブの「画面収録の許可を設定」から許可してください。
- **マウスの設定が効かない・元に戻る**: 「入力監視」の許可を確認してください。SteerMouse や Logi Options などが動いていると設定が上書きされることがあります（設定の「マウス」タブに表示されます）。
- **Dockの表示がおかしくなった**: 設定の「Dock」タブの「フルスクリーン時の表示設定を戻す」を押し、ログアウトしてからログインし直してください。
- **自動アップデートが失敗する**: TKButilが「アプリケーション」フォルダにあるか確認してください。

## プライバシー

クリップボードの履歴と定型文は、このMacの中（`~/Library/Application Support/TKButil/`）にだけ保存し、外部へ送ることはありません。クラッシュレポートはmacOS標準の診断機能に任せ、開発者へ自動で送ることはありません。通信するのは、アップデートの確認（apps.tkbtk.com とGitHub）だけです。
