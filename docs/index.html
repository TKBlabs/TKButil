概要

// overview

TKButilは、メニューバー常駐で運用する総合ユーティリティです。 中核はクリップボード履歴で、テキスト・URL・画像を検索しながら呼び戻せます。

さらに定型文管理、ウィンドウ切り替え、Dock移動抑止、マウス調整、アプリ起動位置指定、サウンド出力優先制御を統合。 それぞれを個別にオン/オフし、必要な機能だけを有効化できる構成です。

主な機能

// features
⧉

クリップボード履歴と定型文入力

テキスト・URL・画像を分類保持し、行数や保持件数を調整しながら高速に再利用できます。定型文の登録と入力にも対応しています。

⌨

ショートカット起動メニュー

キー組み合わせや修飾キー連打で履歴と定型文メニューを表示。キーボード操作中心の運用が可能です。

✎

アプリケーション起動位置固定

アプリケーション起動時に毎回ウィンドウ位置がバラバラになるイライラを解消。指定したモニタ環境下で毎回指定位置に配置します。

▣

Dock移動抑止

複数ディスプレイ環境で、非メイン画面のエッジ誤接触によるDock移動を防止します。

◐

マウス調整

デバイス選択、スクロール速度、カーソル速度・加速、反転動作を調整し、競合検知も行います。

♫

サウンド優先度制御

出力デバイスの優先順位を設定し、接続状態を監視しながら望む出力先へ自動で切り替えます。

# TKButil

日々の細かい作業を助ける機能を1つに集約した、macOS用の総合ユーティリティアプリです。

## インストール

  • DMGを開き、TKButil.app を「アプリケーション」フォルダへドラッグします
  • Appleの公証（Notarization）済みのため、そのままダブルクリックで起動できます
  • 自動貼り付け・ウィンドウ固定・ウィンドウ切り替え・マウス調整を使う場合は、アクセシビリティなどの許可を求められます

## アップデート

  • 24時間ごとに自動で更新を確認し、新しい版があればお知らせします
  • メニューバーアイコンの右クリックメニュー「アップデートを確認...」から手動でも確認できます
  • 自動確認の有無は 設定 → 更新 で切り替えられます

## 動作環境

  • macOS Tahoe 26.5以降
  • Apple Silicon 搭載Mac（Intel Mac非対応）

## 主な機能

  • クリップボード履歴（テキスト・URL・画像）と定型文
  • アプリごとのウィンドウを個別に選べるウィンドウ切り替え（⌘Tab にも割り当て可）
  • モニタ構成ごとのウィンドウ位置固定、複数ディスプレイでのDock移動抑止
  • マウスごとのスクロール・カーソル調整、サウンド出力先の優先度制御
